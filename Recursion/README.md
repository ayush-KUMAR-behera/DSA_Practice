### Sum of Natural Numbers

Approach:
- Use recursion to add `n` with the sum of numbers from `n - 1`.
- Base case: when `n` reaches `1`, return `1`.
- Recursive case: `n + sum(n - 1)`.

Time Complexity: O(n)

Space Complexity: O(n)

Pattern: Recursion
